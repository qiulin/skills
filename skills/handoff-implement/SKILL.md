# 移交实现（Handoff Implement）

实现工作放到干净上下文里做：原会话把需求固化成自足的 prompt（内含冻结的验收标准），新会话照 prompt 实现，原会话再拿一手证据逐条验收。隔离让实现不被原会话的探索噪音干扰，也让验收拥有独立视角。

## 何时使用

- 用户说"生成 prompt 交给新会话实现""新会话来做""严格验收"
- 任务体量大，或与当前会话的上下文基本无关，开新会话实现更干净
- 实现质量需要独立于实现者的把关

## 操作步骤

**阶段一：生成 prompt（原会话）**

1. **固化需求与验收标准**。动手写 prompt 前先把任务写成可验收的形式：目标、范围（做什么/明确不做什么）、技术约束、完成定义。每条验收标准必须可检验——能跑出命令、看到输出、确认文件存在或行为正确。
2. **组装自足 prompt**。新会话没有任何上下文，prompt 必须自足，按此结构：
   - 背景：项目路径、技术栈、相关文件路径，一段话；
   - 任务：目标与范围，明确写出"不做什么"；
   - 验收标准：编号列出，逐条可检验；
   - 输出要求：完成后必须输出执行汇总（模板见阶段三）；
   - 硬约束：不扩展范围、不动范围外的文件；无法决策的问题记入"遗留问题"，禁止靠猜测扩范围。
3. **自足性检查**。假设读者一无所知，逐句问："新会话只靠这段话能行动吗？"所有指代（"刚才说的""那个文件"）都替换为具体路径和结论。

**阶段二：新会话实现**

4. **派生新会话**。工具支持派生子代理就直接派生（天然隔离上下文）；不支持就把 prompt 原样输出，由用户开新会话执行。原会话不替它做实现，实现过程中原会话产生的任何新想法只允许进"整改 prompt"，不插手进行中的实现。

**阶段三：执行汇总（新会话完成时）**

5. **输出执行汇总**，固定四段：
   - 做了什么：改动文件清单 + 每处改动的要点；
   - 怎么验证的：跑过的命令 + 原始结果；
   - 验收自检：对每条验收标准逐条标注 通过/未通过/未涉及；
   - 遗留问题：未做的部分、做主决策了什么、为什么。
   - 实现会话装有 execution-summary skill 时，用它生成自足的可复制版汇总，整体粘贴回验收方。

**阶段四：严格验收（原会话）**

6. **逐条核验，只认一手证据**。验收依据是阶段一冻结的标准，不是汇总的自述。每条标准自己取证：自己跑测试和构建、自己打开改动文件读关键 diff、自己运行程序验证行为、自己核对改动文件清单与声明的范围一致。
7. **裁决并留档**。全部通过 → 宣布验收通过，附"标准 → 证据 → 判定"对照表；任一未通过 → 整体判定为未通过，生成整改 prompt（只含不合格项 + 复验标准），回到阶段二再跑一轮。每轮结果都记录在案。
8. 判定无中间态："基本完成""大体可用"不是验收结论，每条标准只有通过/未通过两种。

完成标准：交付物 = 一份留档的 prompt（含验收标准）+ 一份执行汇总 + 一份逐条验收对照表，三者缺一不算完成。

## 标志性追问

- "新会话只看这份 prompt，能不问任何问题就开工吗？"
- "这条验收标准能跑出什么命令、看到什么现象？"
- "汇总说的'已完成'，我有自己的一手证据吗？"
- "改动文件清单和声明的范围一致吗？"

## 失败模式

- prompt 夹带探索噪音：把原会话试错过程的曲折全塞进去。新会话要的是结论和约束，不是日记；过程细节会让它复现你的弯路。
- 验收被汇总替代：照抄执行汇总宣布通过。汇报是自述，验收必须一手取证——这是本 skill 与"信任并转发"的区别所在。
- 标准事后漂移：实现完了再"回忆"该验什么。标准在 prompt 里冻结，验收逐条对照，临时新增的标准明确标为"追加"并走下一轮。
- 中间态判定：用"差不多了"结束验收。部分通过 = 未通过。

## 示例

- Before：用户："把 CSV 导出做了，交给新会话，做完汇总，你把把关。"
- After：原会话生成 prompt——背景（仓库路径、Web 服务、export 模块位置）；任务（CSV 导出，正确处理引号/逗号/换行转义；不做 Excel 格式）；验收标准（① pytest tests/test_export.py 全绿；② 含引号和逗号的字段导出后用表格软件打开不串列；③ 10 万行导出 < 30s；④ 改动仅限 export/ 目录）；输出要求（执行汇总四段模板）。新会话实现并交汇总。原会话验收：自己跑测试（①过）、自己导一份含特殊字符的数据核对（②过）、自己计时 10 万行（③未过）——整体未通过，整改 prompt 仅含"改为流式写出"；二轮复验 ③ 通过，两轮记录随验收表一并交付。
