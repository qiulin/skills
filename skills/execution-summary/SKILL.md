# 执行汇总（Execution Summary）

实现者负责如实汇报，验收方负责裁定结论。汇总是一份可整体复制、自足的文档：验收方与你会话完全隔离，只靠粘贴过去的这一份内容就要能开始逐条验收——所有指代必须落成路径、编号和 commit。

## 何时使用

- 刚按某份设计/prompt 完成实现，要向原设计会话汇报
- 用户说"输出执行汇总""生成可复制的汇总""交给原会话验收"
- handoff-implement 流程中新会话完成实现时的收尾

## 操作步骤

1. **找到验收契约**。取本次实现依据的 prompt/方案中的验收标准原文（编号 + 原文）。找不到成文标准时，先按自己的理解编号列出，并标注"自拟，待验收方确认"——这不影响后续格式。
2. **采集一手事实**。改动文件清单（`git diff --stat <基线>`）、跑过的验证命令和原始输出、关键 diff 位置（文件:行号）。所有事实从工具结果里取，不凭印象补写。
3. **按模板组装**（五段，见下）。逐条自检对照验收标准**原文**，标注 通过/未通过/未涉及 三态之一，证据列放命令或文件:行号，放原文不转述。
4. **打包为单个可复制代码块**。整份汇总放进一个 fenced block，用户一次复制、整体粘贴。自足性检查：逐句清除"如上/刚才/那个文件"类会话内指代，全部替换为具体路径、标准编号、commit hash；复验命令要能被验收方原样执行。
5. **诚实收尾**。未通过的条目如实标未通过；汇总末行固定注明"以上为实现者自检，最终判定以验收方复核为准"。

## 汇总模板

````markdown
## 执行汇总

- 任务来源：<设计文档/prompt 的名称、日期或开头摘要>
- 代码基线：仓库 <绝对路径>，分支 <分支名>，基线 commit <hash>，当前 <head hash 或"改动未提交">
- 验收标准：<逐条引用原文，编号与验收方一致>

### 1. 做了什么
- <文件路径>：<改动要点>

### 2. 怎么验证的
- `<命令>` → <原始结果摘要>

### 3. 验收自检
| # | 验收标准原文 | 结果 | 证据 |
|---|---|---|---|
| ① | <原文> | 通过 | <命令输出/文件:行号> |

### 4. 遗留问题
- <未做的部分 / 自行做了什么决策、为什么 / 建议验收方重点看哪里>

### 5. 复验指引
- ① `<验收方原样执行的命令>`
- 范围核对：`git diff --stat <基线>` 显示改动仅含上述文件

（以上为实现者自检，最终判定以验收方复核为准。）
````

完成标准：汇总为单个 fenced block，五段齐全，每条验收标准有原文引用和证据，复验命令可原样执行，全文无会话内指代。

## 标志性追问

- "验收方与我会话完全隔离，这份汇总里有依赖上下文的指代吗？"
- "证据是工具输出的原文，还是我的转述？"
- "复验命令能原样跑吗？我跑过一遍吗？"
- "未通过的条目我标了吗，还是'基本完成'了？"

## 失败模式

- 转述漂移：验收标准被换成自己的措辞后含义偏移，验收方对不上号。引用原文和编号。
- 证据靠转述："测试通过"不是证据，`pytest tests/test_export.py → 27 passed` 才是。
- 不可复现：复验命令依赖你会话里的临时状态（未提交的临时文件、环境变量）。要么写清前置条件，要么先固化再写命令。
- 汇总夹辩解：把"我为什么这么做"写成"这是对的"。事实与证据归汇总，结论归验收方。
- 粉饰结果：三态之外没有第四态，"基本完成"按未通过处理。

## 与 handoff-implement 的关系

handoff-implement 阶段三的模板是内嵌在 prompt 里的精简版（prompt 必须自足）；本 skill 是实现者侧的完整模板，四段结构一致、多出"复验指引"和"代码基线"两块。新会话装有本 skill 时优先用它生成。

## 示例

- Before："做完了，测试都过了，你验收一下吧。"
- After：单个代码块，开头"任务来源：订单取消功能设计 v1（2026-09-10）"；基线写明分支 feat/order-cancel、基线 commit `a1b2c3d`、当前未提交；自检表 4 行——① pytest 27 passed（通过）② 含逗号引号字段导出核对（通过，附数据文件路径）③ 10 万行 < 30s（**未通过**，实测 47s，见第 4 段）④ 改动仅限 export/（通过，附 diff --stat 输出）；遗留问题写明"③ 未达标：当前为逐行写出，建议流式改造，涉及 writer.py:L40"；复验指引给出验收方原样可跑的 3 条命令。
